Как пользоваться

◄ — из «Текущих параметров» открывает главное меню; внутри раздела — назад.

► — входит в выбранный раздел меню.

▲ ▼ — перемещение по списку / изменение разряда при редактировании.

ВВОД — войти в редактирование или подтвердить значение. ОТМЕНА — отменить правку.

Работает и клавиатура: стрелки, Enter, Esc.

Задания

1. Открыть главное меню
Нажмите ◄ на экране «Текущие параметры».
2. Раздел «Уставки и защиты»
В главном меню найдите раздел 3 и нажмите ►.
3. Настроить АПВ по перегрузке
Функция 048 «Перегруз двиг.» — установите значение «АПВ».
4. Изменить выходную частоту
В «Текущих параметрах» отредактируйте функцию 003.
5. Пуск и останов
Нажмите ПУСК, затем СТОП.

Журнал оператора

Станция выдаёт случайные показания — считайте их с панели тренажёра (как во время обхода) и впишите значения вручную. Кнопка «Проверить» сверит ваш ввод с реальными данными станции.

ПараметрЗначениеЕд. изм.
Проверка (тест)

Считайте новые показания с панели и впишите вручную, затем нажмите «Проверить» — верные поля станут зелёными, неверные красными.

Тренировка (подсказка)

Подставляет верные значения — используйте для обучения, не для самопроверки.

Задание технолога

Журнал принят. Технолог просит внести изменения на станции — найдите нужные функции через меню, установите указанные значения (клавиша ВВОД, затем ◄►▲▼) и нажмите «Проверить изменения».

    Неофициальный учебный тренажёр по материалам РЭ «ЭЛЕКТОН-05» (ЦТКД 065РЭ). Значения по умолчанию иллюстративны.
